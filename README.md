# 🧠 Todo List App

Basit, hızlı ve modern bir yapılacaklar listesi uygulaması.  
Görev ekleyebilir, silebilir ve tarayıcıda **localStorage** sayesinde verileri kalıcı olarak saklayabilirsiniz.

---

## 🚀 Özellikler

- Görev başlığı ve açıklama ekleme
- Görevleri silme
- LocalStorage ile veri kalıcılığı
- Tıklanınca görev detayını büyütme efekti
- Responsive ve sade arayüz

---

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- LocalStorage API

---

📌 Geliştirme Fikirleri

Düzenleme (edit) özelliği
Filtreleme (tamamlanan / aktif görevler)
Dark / Light mode
